# Portfolio Design Rule

> **Let the work be the color and the designer be the type.**

---

## The Rule in Practice

1. **The page is a neutral canvas** — white background, monochrome chrome, one accent color maximum. All visual richness comes from the project thumbnails, never the page itself.

2. **The hero is your name, sized like a billboard** — no headshot, no illustration, no carousel. Identity is expressed through a typographic statement (3–5× body text size) plus a single-line tagline naming where you've worked.

3. **Every project is a single image that earns a click** — large rounded thumbnail (~80% of the card), ≤ 2 lines of text, no borders or shadows. If the image doesn't sell the project, fix the image — don't add more words.

4. **Structure is always Nav → Hero → 2-Col Grid → Footer** — no sidebars, no parallax sections, no multi-layout pages. Deviation from this skeleton needs explicit justification.

5. **Whitespace is load-bearing** — wide margins (8–15% of viewport), generous gutters (16–32px), and breathing room between sections. When in doubt, add more space, not more content.

6. **Navigation disappears** — ≤ 4 links, no dropdowns, visually quiet. The nav is a utility, never a feature.

7. **The footer is human** — end with a warm, conversational sign-off and contact links. This is the one place personality outranks minimalism.

---

## Decision Filter

When evaluating any design choice, ask:

- **Does this draw attention away from the project images?** → Remove it.
- **Does this add visual noise to the page chrome?** → Simplify it.
- **Does this require more than 2 seconds to understand?** → Rewrite it.
- **Would this still look good with 50% more whitespace around it?** → Add the whitespace.
