# Case Study Analysis: CryptoHub (Nelly Rodicheva)

**Reference URL:** [nellyrodicheva.com/work/cryptohub](https://nellyrodicheva.com/work/cryptohub)

## Visual & UI Design

### 1. Visual Identity
- **Color Palette:** Light mode with **Royal Blue** (Headings) and **Deep Red** (Logos, Buttons).
- **Enterprise Aesthetic:** High-trust, professional look. Clean lines, ample whitespace, and high contrast.
- **Typography:** Large, bold sans-serif headings that drive the narrative.

### 2. Layout Patterns
- **Sticky Section Labels:** A sticky sidebar labels current sections (Context, Problem, Results) as you scroll.
- **Logical Flow:** Hero → Role/Timeline/Tasks/Tools Grid → Problem (Quotes) → UI Audit → Solution → Results.
- **Context Grid:** Uses a 4-column layout at the top to quickly establish project scope.

### 3. Technical & Data Visuals
- **Metric Cards:** High-level summary numbers (e.g., pending keys) placed above detailed data tables.
- **Annotated Components:** Callouts explain specific UI decisions (e.g., "Danger looks dangerous" for red action buttons).
- **Data Tables:** Clean, organized tables with consistent status badges and action menus.

### 4. Spacing & Hierarchy
- **Section Breaks:** Major narrative shifts are marked by large headings and significant spacing.
- **Visual Evidence:** Uses "before" (Audit) and "after" (Solution) comparisons to show value.

---

## Content & Storytelling
- **Narrative Headings:** Headings are descriptive and could tell the story on their own.
- **Real-World Validation:** Includes photos of the product at trade shows/conferences for social proof.
- **Problem-first:** Clearly defines the "Why" using user quotes and chat bubbles before showing any UI.
