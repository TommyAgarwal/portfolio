# Reference 1 — Rebecca's Portfolio

## Overview
An empathetic UX designer portfolio with a playful, hand-drawn aesthetic layered on top of a clean white layout. Emphasis on personality and approachability.

---

## Layout & Structure

- **Navigation**: Minimal top bar — small logo/icon top-left, "about" link top-right. Very understated.
- **Hero Section**: Large, hand-drawn cursive name ("rebecca") with decorative swooping lines in a soft teal/cyan color. Below it, a one-line tagline in a clean sans-serif: *"an empathetic UX designer making data backed decisions."*
- **Sub-tagline**: Smaller text listing affiliations — "Design @Georgia Tech / UX @Delta Air Lines / Incoming UX @Google"
- **CTA & Social Row**: Horizontal row of pill tags (`UX/AI`, `IN`, `UXR`) plus a teal CTA pill ("☆ My Work ↓") followed by LinkedIn and email icons.
- **Project Grid**: 2-column grid of project cards, 3 rows = 6 projects. Below the grid, a footer.
- **Footer**: Minimal — left-aligned contact info, right-aligned copyright and short bio blurb.

## Spacing & Proportions

- **Hero section** takes roughly the top 20–25% of the viewport. Generous vertical padding above and below the name.
- **Project grid** has consistent spacing between cards — approximately 16–24px gutters.
- **Cards** are roughly equal width in each column but variable height depending on the thumbnail image aspect ratio.
- **Generous whitespace** around the entire page — wide left/right margins (~8–10% of viewport width).

## Color Palette

| Role | Color | Notes |
|------|-------|-------|
| Background | `#FFFFFF` (pure white) | Clean, minimal canvas |
| Accent | Soft teal/cyan (`~#5CC8C8`) | Used for hand-drawn lines, CTA pill, and subtle highlights |
| Text Primary | Dark charcoal / near-black | For headings and body text |
| Text Secondary | Medium gray | For sub-taglines, descriptions |
| Tag Pills | Light gray background with dark text | Project category tags |
| Accent Tag | Teal background with white text | "UX/AI" tag uses the accent color |

## Typography

- **Name/Hero**: Hand-drawn / script font — cursive, loose, organic feel. Very large scale. This is arguably the most distinctive element.
- **Tagline**: Clean sans-serif (likely Inter, DM Sans, or similar), medium weight, ~18–20px.
- **Sub-tagline & body**: Same sans-serif family, lighter weight, smaller size (~14px).
- **Project titles**: Bold sans-serif, ~16–18px.
- **Project descriptions**: Regular weight, ~13–14px, medium gray.
- **Tag pills**: Small caps or uppercase, ~10–12px.

## Card Design

- **Thumbnail**: Rounded rectangle images (subtle `border-radius: ~12–16px`). Show actual product mockups — phones, screens, UI screenshots.
- **Title**: Bold, directly below the image.
- **Description**: One-line description of the project.
- **Tags**: Row of small pill-shaped category labels (e.g., "UX/AI", "UX Designer", "Dev + Design").
- **No visible borders or shadows** on cards — the card is essentially image + text stacked vertically on the white background.
- **Hover effects**: Not visible from screenshot, but likely subtle scale or shadow.

## Unique Design Patterns

1. **Hand-drawn illustration as hero** — the cursive name with swooping organic lines is the hero visual. No photo, no 3D graphic. Creates warmth and personality.
2. **Teal accent used sparingly** — only in the decorative lines and a few interactive elements. Everything else is neutral.
3. **Pill-shaped tags** — used both in the hero section (role identifiers) and on each project card (category labels). Consistent component language.
4. **CTA with star icon** ("☆ My Work ↓") — playful micro-copy, inviting scroll.
5. **Mixed project types** — includes both digital (app UIs) and physical (furniture design), signaling breadth.
6. **No hero image or photo of the designer** — identity communicated through illustration and copy alone.

## Overall Vibe
**Approachable · Playful · Clean · Personal · UX-focused**

The portfolio balances personality (via the hand-drawn elements) with professionalism (via the clean grid and restrained color palette). It reads as someone who cares about craft and warmth.
